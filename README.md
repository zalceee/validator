## CSV VALIDATOR FOR SALES UPLOADER
---
### HOW TO USE
---

1. Copy the .exe file where the csv file located or save the file to any folder you prefer and add to variable PATH.

2. Open CMD and check the directory to where the csv file located.

3. Type "validate [csvname].csv" and press enter.

---
## GENERATE FORMAT
---

1. Copy the formatgenerate.exe to the location of the dsr csv file

2. Download the spreadsheet csv delimited data.

3. Edit the CSV delete "POS Receipt #/ Date Transacted", "Inventory Type" column and replace card to "Credit Card" and save.

4. Open cmd and go to the formatgenerate.exe path.

5. use to code to generate format " formatgenerate dsr.csv [Year]-[Month]-[Day]
